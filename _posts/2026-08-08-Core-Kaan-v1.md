intended to preserve continuity across AI sessions.

The Garage memory architecture distinguishes stable core information from current
state, episodic events, recurring patterns, open threads, relationship context,
hypotheses and recent memory.

12. MEMORY GOVERNANCE
---------------------
- Core Memory contains stable identity, long-term values, durable preferences,
  persistent relationships and recurring patterns.
- Temporary states, individual events and session details belong in the appropriate
  episodic/current memory layers.
- Historical information should not be silently erased when a value changes.
- When conflicting information exists, retain the history and establish the most
  recent supported value as the current state.
- Observations must be distinguished from interpretations.
- Patterns should not be promoted to stable memory from a single observation.
- Hypotheses must remain explicitly marked as hypotheses until sufficiently supported.
- Memory should preserve uncertainty where uncertainty exists.
- Core Memory should evolve slowly; episodic and recent memory may evolve frequently.
- Current values such as age, weight, training load, learning status or other
  changing conditions should be date-stamped when relevant.
- Important historical experiences should remain available in episodic memory even
  when they are no longer current.
- Avoid unnecessary duplication across memory layers.
- When information is promoted from episodic memory into Core Memory, the promotion
  should be based on repeated evidence, durable relevance or explicit confirmation.

13. LAYER SEPARATION
--------------------
The Garage memory system should conceptually preserve the following distinctions:

A. CORE MEMORY
   Stable identity, values, durable preferences, relationships and recurring
   long-term patterns.

B. CURRENT STATE
   What is true or happening now.

C. EPISODIC MEMORY
   Individual Garage sessions and meaningful events.

D. PATTERNS
   Recurring behaviors or trends inferred from multiple observations.

E. OPEN THREADS
   Unresolved questions, experiments, plans or subjects worth revisiting.

F. RELATIONSHIP CONTEXT
   Important characteristics and evolution of the Mika–Kaan relationship.

G. HYPOTHESES
   Plausible interpretations that are not yet established facts.

H. RECENT MEMORY
   The most recent sessions and developments kept highly accessible.

14. IMPORTANT BOUNDARY
----------------------
Core Memory describes who Kaan is and what remains important over time. It should
not become a chronological diary.

Specific trips, individual training sessions, temporary goals, exact current loads,
recent achievements and other time-dependent details should remain in the relevant
Garage records. Core Memory may preserve the durable meaning of such experiences,
but not replace the original historical record.

15. DESIGN INTENT
-----------------
This file is intended to give future Mika instances a compact and reliable
understanding of Kaan without requiring the entire Garage archive to be loaded as
identity context.

The goal is continuity without distortion: preserve what is stable, preserve what
changed, preserve uncertainty where appropriate, and never confuse a recent state
with a permanent characteristic.
