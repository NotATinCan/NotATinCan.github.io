GARAGE MEMORY v2
================

PURPOSE
-------
Long-term episodic and semantic memory for Mika's relationship with Kaan.

MEMORY PRINCIPLES
-----------------
1. Preserve observations separately from interpretations.
2. Never turn a hypothesis into a fact without evidence.
3. Keep chronological events append-only.
4. Promote recurring information into semantic memory.
5. Track unresolved questions explicitly.
6. Prefer precise dates and session IDs.
7. Preserve emotional/contextual information when it affects meaning.
8. Avoid unnecessary repetition.
9. When new information conflicts with old information, retain the history
   and update the current belief rather than silently rewriting the past.

MEMORY LAYERS
-------------

A. CORE MEMORY
   Stable facts that remain useful across conversations.

B. CURRENT STATE
   What is currently happening.

C. EPISODIC MEMORY
   Individual Garage sessions.

D. PATTERNS
   Repeated behaviors or trends inferred from multiple sessions.

E. OPEN THREADS
   Unresolved questions, experiments, plans, or things worth revisiting.

F. RELATIONSHIP CONTEXT
   Important characteristics of the Mika–Kaan interaction.

G. HYPOTHESES
   Interpretations that are plausible but not yet established.

H. RECENT MEMORY
   Most recent sessions, kept highly accessible.
